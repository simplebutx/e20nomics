## 프로젝트 소개

**e20nomics**는 경제 뉴스와 경제 용어를 쉽게 이해할 수 있도록 돕는 **AI 기반 경제 학습 서비스**입니다.

사용자는 경제 뉴스 요약, 경제 용어 설명 생성, 개인 용어장 저장, 요약 콘텐츠 관리를 통해 어려운 경제 정보를 자신의 수준에 맞게 학습할 수 있습니다.  
관리자는 오늘의 경제 뉴스, 경제 용어, 뉴스 이미지 등을 생성하고 관리할 수 있습니다.

- 개발 기간: 2026.02-2026.03
- 참여 인원: 1명
- 담당 역할: 프론트 / 백엔드 / AI
- 프로젝트 유형: 경제 뉴스 요약 및 경제 용어 학습 서비스

## 주요 기여

### 백엔드 API

- 사용자 인증, 마이페이지, 관심 설정 기능을 구현했습니다.
- 경제 뉴스 조회 및 상세 조회 API를 구현했습니다.
- 사용자가 생성한 요약 콘텐츠와 개인 용어장을 저장하고 관리할 수 있는 CRUD API를 구현했습니다.
- 관리자 권한으로 뉴스, 용어, 이미지를 관리할 수 있는 API를 구현했습니다.

### AI 기능 연동

- FastAPI 기반 AI 서버를 구성하고 Spring Boot 백엔드와 연동했습니다.
- OpenAI API를 활용해 경제 뉴스 요약, 경제 용어 설명, 뉴스 이미지 생성 기능을 구현했습니다.
- 사용자가 입력한 텍스트를 기반으로 요약 결과를 생성하고, 생성된 결과를 저장할 수 있도록 백엔드 흐름과 연결했습니다.
- 경제 용어를 입력하면 AI가 쉬운 설명을 생성하고, 사용자가 개인 용어장에 저장할 수 있도록 구현했습니다.

### 관리자 기능

- 관리자가 오늘의 경제 뉴스를 생성, 조회, 수정, 삭제할 수 있도록 구현했습니다.
- 관리자가 경제 용어를 생성하고 관리할 수 있는 기능을 구현했습니다.
- 뉴스 이미지 생성을 AI 서버와 연동하고, 생성된 이미지 정보를 뉴스 데이터와 연결했습니다.
